Anexo A9 · Implementación con Sirv

La implementación cabe en la plantilla: marcado, preload alineado y CSS de relevo

1 · Marcado

<div class="image-gallery">
 <picture class="pdp-foto">
  <source media=
   "(min-width:1024px)"
   srcset="…w=700&h=0">
  <img src="…w=400&h=0"
   fetchpriority="high"
   alt="{producto}">
 </picture>
 <div class="Sirv" …>
</div>

2 · Preload alineado

Misma URL que pide Sirv, carácter por carácter:

celular:
 …w=400&h=0
computador:
 …w=700&h=0

Hoy: w=800&h=0&q=60 en celular (no coincide) y otra ruta en computador.

3 · CSS de relevo

.pdp-foto {
 position:absolute;
 object-fit:contain }
/* misma área que Sirv */
celular: inset 0 0 70px 0
computador: inset 0 0 0 95px
.is-ready .pdp-foto {
 visibility:hidden }

La foto va al lado del visor de Sirv, no adentro. Sin loading="lazy". Sin JavaScript nuevo: initSirv() ya marca is-ready. Guía completa: docs/03-implementacion-foto-sirv.md en el repositorio.

Medidas de la galería tomadas el 02.10.2026 con viewport de 412 px y 1365 px; verificar en tablet

A9

Para el equipo de desarrollo: tres piezas. El marcado agrega la primera foto al lado del visor de Sirv. El preload pide exactamente la misma URL que Sirv usa después, así la imagen se descarga una sola vez. Y el CSS coloca la foto en la misma área que la diapositiva de Sirv y la oculta cuando Sirv está listo, sin salto visual. No hace falta JavaScript nuevo. La guía completa con la lista de control está en el repositorio.
