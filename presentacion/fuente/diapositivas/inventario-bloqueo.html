A5

Estos son los elementos que detienen la lectura del HTML. El más dañino es Reviews.io. El segundo es un CSS de jsDelivr sin número de versión, ubicado justo antes de un script inline: los scripts inline esperan a todo el CSS anterior, así que si ese archivo se cuelga, se cuelga toda la página. Varify es el único que la métrica clásica marca como bloqueante. En la PDP de Dell además aparece el widget de IA de Alkosto, cargado síncrono y con datos de plantilla sin reemplazar.
